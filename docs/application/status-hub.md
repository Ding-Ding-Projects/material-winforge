# Desktop Status Hub reference

The desktop design reference includes the same evidence-first Status Hub concept: current release metadata, explicit evidence lanes, and a visible boundary between local facts and unverified runtime or remote delivery.

The landing page is not the desktop runtime. It cannot inspect the installed application, authenticate to a shared inbox, or claim packaged-runtime evidence. Those states remain labelled as waiting or unavailable until a separate approved evidence run records them.

## Verification

This article records the design and documentation contract only. No desktop build, runtime interaction, accessibility review, capture, or remote delivery was run for this lane.
