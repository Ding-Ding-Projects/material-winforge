# Desktop element appearance editor

The desktop design reference now carries the same bounded appearance-editor contract as the site: an anchored card preview with local persistence, per-element reset, typography weight/style, underline/strikethrough, spacing, line-height, direction/alignment, continuous color/alpha controls, preset disclosure, and explicit unsupported-property copy.

The reference is design data, not a claim that the packaged desktop runtime has been independently exercised. No credentials or network route is present. OKLab conversion remains explicitly unsupported in this bounded slice; HEX, RGBA, HSLA, HSVA, HWB, and CMYK representations plus contrast-ratio disclosure are shown. Gradients, shadows, variable-font axes, and custom underline styles remain explicitly unsupported rather than guessed.
