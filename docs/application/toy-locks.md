# Desktop toy locks and Support Tickets

The desktop design reference defines the same major-target toy-lock contract as the landing surface: independently salted local credential hashes, selectable unlock duration, locked-state disclosure in search and palette, relock, and a self-service local application-data recovery path. The lock is explicitly for fun and is not security or encryption.

Support Tickets is a local fictional desk. It records only bounded recovery notes and explains that no network request, remote ticket, data collection, or human support channel exists. The user opens the local application-data folder and performs deletion themselves; the app never silently deletes it.

Verification boundary: the design-reference source and documentation are updated. Built desktop interaction, tests, lint, captures, and packaged artifact verification remain unverified.
