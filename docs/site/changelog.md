# Changelog viewer

The Changelog tab presents the same five published `v1.0.31`–`v1.0.35` records as the desktop catalogue, with exact dates, commit subjects, SHAs, and commit links. It has its own plain-text search, adjacent JavaScript regex builder, ISO date range, no-match state, clipboard copy, and Markdown export.

All data is bundled locally. The viewer performs no network lookup and does not reinterpret an unreleased commit as a release. Version, date, and commit facts remain outside personal-vocabulary and tone transformations.

Runtime browser interaction, invalid-pattern recovery, date edges, copy/download behavior, keyboard traversal, and responsive layout remain unverified in this ultra-speed slice.
